# Backlog Label INPG

## US-01 - Découvrir le Label INPG

En tant que visiteur, je veux comprendre les volets, les niveaux et les étapes du Label INPG afin d'identifier le parcours adapté.

### Critères d'acceptation

- Le portail public présente les volets Sécurité, Qualité et Environnement.
- Il explique les niveaux Standard, Gold et Platinum, avec le nombre de volets requis.
- Il affiche les sept étapes du parcours de certification.
- Les principaux appels à l'action donnent accès à la demande de certification et à la vérification d'un certificat.
- La mise en page reste exploitable sur mobile et au clavier.
